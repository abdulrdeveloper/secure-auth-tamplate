🚦 End-to-End User Journey Walkthrough

Jab koi user website par ata hai, files kis sequence mein load hoti hain aur backend ke kon se controllers trigger hotay hain:

STAGE 01 GET /
1. App Bootstrapping & Route Routing
User browser mein http://localhost:5173 open karta hai. Browser server se index.html leta hai aur React app mount hoti hai.
Frontend Entry Points

1. frontend/index.html (Root DOM container <div id="root">)

2. frontend/src/main.tsx (Creates React root & loads index.css)

3. frontend/src/App.tsx (Browser Router starts here)

Routing Decision

App.tsx ke andar <Route path="/" element=<Navigate to="/login" replace />> laga hua hai.

Browser foran redirect ho kar /login par chala jata hai.

Layout Applied

frontend/src/components/auth-layout.tsx

Left side: Brand Panel (Logo + "Private by design")

Right side: Form Container jahan <LoginPage /> render hota hai.

STAGE 02 POST /api/auth/register
2. New User Registration & OTP Issuance
User Register form fill karta hai (Full Name, Email, Password). Backend data validate karta hai, password hash karta hai, aur Resend ke through email bhejta hai.
Frontend Execution

frontend/src/pages/auth/register.tsx

Calls: apiRequest("/register", { data: form }) via frontend/src/lib/api.ts.

Starts 60s cooldown via frontend/src/lib/otp-cooldown.ts aur user ko /verify-email?email=... par redirect karta hai.

Backend Validation & Controller

backend/src/middlewares/validate.middleware.ts checks input with registerSchema in backend/src/config/validation.ts.

backend/src/controllers/register.controller.ts hashes password via bcrypt and saves user to MongoDB.

Services Triggered

backend/src/services/otp.service.ts: Generates 6-digit OTP, saves in Upstash Redis with 300s expiry.

backend/src/services/mail.service.ts: Resend API se verification email send karta hai.

STAGE 03 POST /api/auth/verify-email
3. OTP Verification & Automatic Sign-In
User inbox se 6-digit OTP code dekh kar enter karta hai. Backend Redis mein rate-limit ke sath check karta hai, user ko verify mark karta hai aur JWT cookie issue karta hai.
Frontend Page & Timer

frontend/src/pages/auth/verify-email.tsx

Timer Hook: frontend/src/hooks/use-cooldown.ts 60 seconds ka live countdown handle karta hai.

Verification hone par frontend/src/components/auth-status.tsx success screen dikha kar 1.2s baad /dashboard bhej deta hai.

Backend Rate-Limiting & Verify

backend/src/controllers/verify-email.controller.ts

verifyOtpWithRateLimit(): Redis mein 5 wrong attempts check karta hai. Agar galat ho to block karta hai.

User Model update: isEmailVerified = true, verificationExpiresAt = null.

Token & Cookie Helpers

backend/src/utils/token.util.ts: setAuthCookie(res, user._id) JWT create karta hai aur secure httpOnly cookie set karta hai.

backend/src/utils/user.util.ts: toPublicUser(user) password strip karke clean response deta hai.

STAGE 04 POST /api/auth/login
4. Returning User Login
User Email aur Password enter karta hai. Backend credentials match karta hai aur check karta hai ke kya email verified hai ya nahi.
Frontend Form

frontend/src/pages/auth/login.tsx

Components: Field (Email), PasswordField (with eye icon toggle).

Success hone par seedha /dashboard redirect karta hai.

Backend Controller

backend/src/controllers/login.controller.ts

1. userModel.findOne({ email }).select('+password')

2. bcrypt.compare(password, user.password)

3. if (!user.isEmailVerified) return 401

4. setAuthCookie(res, user._id)

STAGE 05 GET /api/auth/me
5. Protected Dashboard & Auth Middleware
User dashboard par aata hai. Browser automatically HTTP cookie ke sath /me request bhejta hai. Agar cookie valid ho tabhi profile show hoti hai, warna foran /login par kick out kar diya jata hai.
Frontend Dashboard

frontend/src/pages/dashboard/index.tsx

useEffect mein apiRequest("/me") call karta hai. User ka name, email aur verified status cards mein render hota hai.

Auth Middleware Guard

backend/src/middlewares/auth.middleware.ts

Cookie ya Bearer token se JWT nikal kar jwt.verify() karta hai. Valid hone par req.userId attach kar ke controller ko pass karta hai.

Me Controller

backend/src/controllers/me.controller.ts

MongoDB se userModel.findById(req.userId) fetch karke toPublicUser() ke through return karta hai.

STAGE 06 POST /forgot-password & /reset-password
6. Two-Step Password Recovery
Forgot password flow do steps mein mukammal hota hai: Pehle email par OTP mangwaya jata hai, phir OTP verify hone ke baad naya password save hota hai.
Step 1: Request Reset OTP

frontend/src/pages/auth/forgot-password.tsx

Backend: backend/src/controllers/forgot-password.controller.ts Anti-enumeration protection ke sath Redis OTP aur Resend Email send karta hai.

Step 2: Verify & Change Password

frontend/src/pages/auth/reset-password.tsx

1. /verify-reset-otp: OTP valid hai ya nahi (consume kiye baghair) check hota hai.

2. /reset-password: Naya password hash ho kar DB mein update hota hai aur Redis se OTP delete ho jata hai.

STAGE 07 POST /api/auth/logout
7. Logout & Session Termination
User Dashboard par "Sign out" button press karta hai. Modal confirmation ke baad cookie clear hoti hai aur user login screen par wapas chala jata hai.
Frontend Dialog

Dashboard page par accessible modal dialog khulta hai. Confirm karne par apiRequest("/logout", { method: "POST" }) trigger hoti hai.

Backend Cookie Clear

backend/src/controllers/logout.controller.ts

res.clearCookie("token", COOKIE_CLEAR_OPTIONS)

Cookie browser se destroy ho jati hai.

🗺️ Complete System Architecture (Naqsha)

Browser se Database tak tamam layers ka aapsi rabta aur data transfer:

1. Client Tier (React 18 + Vite 6 + Tailwind v4)
💻 User Browser
📦 App.tsx (Router)
🎨 AuthLayout & UI Primitives
⚡ useCooldown & API Client
⬇️ [HTTP Requests / JSON / httpOnly Cookies] ⬇️
2. Express Server Tier (Port 3000)
🚀 server.ts
🛡️ CORS (Origin 5173)
🍪 cookie-parser
🔒 auth.middleware.ts (JWT Guard)
📋 validate.middleware.ts (Zod)
⬇️ [Routes Dispatcher] ⬇️
3. Controllers & Utility Helpers
👤 register.controller
🔑 login.controller
✉️ verify-email.controller
🔄 reset-password.controller
🧰 token.util.ts (setAuthCookie)
🧹 user.util.ts (toPublicUser)
⬇️ [Data & Storage Operations] ⬇️
4. Infrastructure & Database Tier
🍃 MongoDB (Mongoose User Schema & TTL Index)
⚡ Upstash Redis (OTP Store, Expiry, Rate Limits)
📧 Resend API (Transactional Auth Emails)

📂 Complete File-by-File Catalog

Codebase ki har ek file ka purpose, wo kaha se call hoti hai aur kisko call karti hai:

frontend/src/main.tsx
React client application ka main mounting entry-point. HTML ke #root div ko pakad kar React application mount karta hai aur global CSS load karta hai.
Loads: index.html
Imports: App.tsx, index.css
frontend/src/App.tsx
Client-side central routing table (React Router v7). Tamam auth pages ko AuthLayout wrapper ke andar group karta hai aur /dashboard protected route define karta hai.
Loaded by: main.tsx
Imports: AuthLayout, All Pages
frontend/src/components/auth-layout.tsx
Auth pages ka consistent split-screen layout. Left side par brand branding/logo aur right side par form injection card provide karta hai. Isme Logo aur AuthHeader components bhi shamil hain.
Loaded by: App.tsx
Renders: Outlet / Children
frontend/src/components/auth-fields.tsx
Form input fields ka reusable bundle. Field, NameField, PasswordField (password toggle button ke sath), OtpField, SubmitButton (loading spinner ke sath) aur ErrorMessage alert box.
Used by: login.tsx, register.tsx, reset-password.tsx, forgot-password.tsx
frontend/src/components/auth-status.tsx
Universal success state card. Email verify hone par aur password reset complete hone par green checkmark icon ke sath informative screen render karta hai.
Used by: verification-success.tsx, reset-password.tsx
frontend/src/hooks/use-cooldown.ts
Custom React hook jo OTP resend ke liye 60-second ka countdown timer manage karta hai. Window interval aur localStorage sync ko handle karta hai taake refresh par bhi timer barkarar rahe.
Used by: verify-email.tsx, reset-password.tsx
frontend/src/lib/api.ts
Centralized HTTP fetch client. Backend base URL resolve karta hai, credentials: 'include' bhejta hai taake cookies transfer hon, aur backend ke JSON error messages extract karta hai.
Used by: Tamam pages aur dashboard
frontend/src/lib/otp-cooldown.ts
Pure helper utilities for OTP timers: getOtpCooldownKey, getCooldownRemaining, aur startOtpCooldown. LocalStorage mein timestamp store karti hai.
Used by: use-cooldown.ts, register.tsx, forgot-password.tsx
frontend/src/pages/auth/login.tsx
User login screen. Email aur password collect karta hai aur backend ke /login endpoint ko call kar ke user ko dashboard bhejta hai.
Calls: POST /api/auth/login
frontend/src/pages/auth/register.tsx
New user registration page. Name, email aur password collect karke /register par submit karta hai aur verify-email page par navigate karwata hai.
Calls: POST /api/auth/register
frontend/src/pages/auth/verify-email.tsx
OTP verification page. 6-digit code input karta hai, resend button with countdown dikhata hai, aur verify hone par dashboard bhejta hai.
Calls: POST /api/auth/verify-email & /resend-otp
frontend/src/pages/auth/forgot-password.tsx
Password recovery initiation page. User ka email mangta hai aur /forgot-password par OTP send karwa kar /reset-password par bhejta hai.
Calls: POST /api/auth/forgot-password
frontend/src/pages/auth/reset-password.tsx
2-Step recovery flow: Step 1 mein OTP verify karta hai aur Step 2 mein naya password aur confirm password set karwata hai.
Calls: POST /verify-reset-otp & /reset-password
frontend/src/pages/dashboard/index.tsx
Protected user dashboard. /me call karke user ka data load karta hai, profile aur account status display karta hai, aur logout confirmation modal handle karta hai.
Calls: GET /api/auth/me & POST /logout
backend/server.ts
Backend entry-point. Environment variables load karta hai, MongoDB database connect karta hai aur port 3000 par HTTP listener start karta hai.
Imports: app.ts, db.ts
backend/src/app.ts
Express app setup: CORS configuration (Origin 5173 with credentials), JSON body parser, cookie-parser aur /api/auth router mounting.
Mounts: /api/auth -> auth.routes.ts
backend/src/routes/auth.routes.ts
Master authentication router. Tamam HTTP routes (login, register, OTPs, password reset, me, logout) ko Zod validation middlewares aur controllers ke sath map karta hai.
Uses: validate.middleware, auth.middleware, controllers
backend/src/models/user.model.ts
Mongoose User Schema. Email, name, hashed password (select: false), emailVerified status, aur TTL auto-delete index for unverified accounts define karta hai.
Used by: Tamam auth controllers
backend/src/middlewares/auth.middleware.ts
Route protection guard. Incoming request ki cookie (ya Authorization Bearer header) se JWT token check karta hai, verify karta hai aur req.userId attach karta hai.
Protects: GET /api/auth/me
backend/src/middlewares/validate.middleware.ts
Generic Zod validation middleware. Request body ko Zod schema ke khilaf check karta hai. Agar error ho to 400 aur exact field errors return karta hai.
Used on: register, login, OTP, reset routes
backend/src/config/cookie.config.ts
Single source of truth for cookies: COOKIE_OPTIONS (httpOnly, secure in prod, sameSite lax/none, 1 hour) aur COOKIE_CLEAR_OPTIONS (for logout).
Used by: token.util.ts, logout.controller.ts
backend/src/utils/token.util.ts
Centralized JWT helper: setAuthCookie(res, userId). JWT create karta hai aur response cookie mein set kar ke token return karta hai.
Used by: login.controller.ts, verify-email.controller.ts
backend/src/utils/user.util.ts
Data sanitizer: toPublicUser(user). Mongoose user object se password aur internal verification fields strip karke safe public data return karta hai.
Used by: login, verify-email, me controllers
backend/src/services/otp.service.ts
Redis OTP engine. Cryptographic 6-digit random code generation, 5-minute expiry, 60s cooldown enforcement, aur 5-attempt rate-limiting logic handle karta hai.
Used by: register, verify-email, reset controllers
backend/src/services/mail.service.ts
Resend email delivery service. Unified HTML email layout renderer jo verification aur password reset emails ke liye stylish branded HTML emails dispatch karta hai.
Uses: Resend API SDK
backend/src/services/redis.service.ts
Upstash Redis REST client instantiation using @upstash/redis. Serverless-ready HTTP Redis connection.
Used by: otp.service.ts
